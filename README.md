# Naive Bayes Classification using Python

This project demonstrates how **Naive Bayes Classification** can be used to predict class labels based on **probability theory and Bayes’ Theorem**. Naive Bayes is widely used for classification tasks due to its simplicity, efficiency, and strong performance on text and categorical datasets.

---

## 🔍 Objective
To implement and evaluate a **Naive Bayes Classifier** capable of predicting class labels using conditional probabilities.

---

## 🧰 Tools & Libraries Used
- **Python**  
- **NumPy**, **Pandas** – data preprocessing  
- **Matplotlib**, **Seaborn** – visualizations  
- **Scikit-learn** – implementing Naive Bayes models and evaluation metrics  

---

## 📊 Project Workflow
1. **Data Loading & Exploration** – inspect dataset distribution  
2. **Data Preprocessing** – cleaning, encoding, scaling (if needed)  
3. **Model Training** – train a Naive Bayes classifier  
4. **Prediction** – classify test samples  
5. **Evaluation** – Accuracy Score, Confusion Matrix, Classification Report  
6. **Visualization** – distribution plots and confusion matrix  

---

## 📈 Results
The Naive Bayes model efficiently classifies the dataset by calculating class-wise probabilities. It performs well even with limited training data and simple feature relationships.

---

## 🚀 Key Learnings
- Understanding **Bayes’ Theorem** and conditional probability  
- How Naive Bayes assumes **feature independence**  
- Difference between **Gaussian, Multinomial, and Bernoulli Naive Bayes**  
- Using probability-based models for classification
